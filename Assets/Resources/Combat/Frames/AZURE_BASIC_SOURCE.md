# Azure Warden basic attack VFX

Each combo frame was generated as its own standalone transparent image with the built-in ImageGen tool, then resized individually to 256 x 256 using nearest-neighbor sampling. No sprite sheet was sliced and no frame is an opacity-only duplicate.

- Combo 1: shield sweep (`AzureBasicShieldSweep_6f`)
- Combo 2: aegis-lance thrust (`AzureBasicLanceThrust_6f`)
- Combo 3: shield slam (`AzureBasicShieldSlam_6f`)
