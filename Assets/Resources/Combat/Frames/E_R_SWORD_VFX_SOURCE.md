# E/R sword VFX sources

The four animation sequences in this directory were generated as individual
transparent images with the built-in image generation tool. No sprite sheet was
created or sliced.

- `E_SpinSlash_6f`: six 128x128 PNG files.
- `AshenJudgmentRunePixel_6f`: six 128x128 PNG files.
- `AshenJudgmentBladesPixel_6f`: six 192x192 PNG files.
- `AshenJudgmentFinalPixel_6f`: six 192x192 PNG files.

The existing Sword Wave and slash effects were used only as palette and pixel
style references. Final assets use Point filtering, Clamp wrapping, no mipmaps,
uncompressed texture data, and one fixed canvas centre per sequence.
