# Azure Warden tanker skill VFX

Q (`AzureAegisRam_6f`), E (`AzureBastionGuard_6f`) and R (`AzureCitadelCollapse_6f`) each contain six standalone PNG files. Every frame was produced by a separate ImageGen call and then individually trimmed and resized onto a transparent 256x256 canvas. No sprite sheet was generated or sliced, and no frame is an opacity-only duplicate.
