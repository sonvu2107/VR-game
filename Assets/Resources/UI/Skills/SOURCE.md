# Skill icon sources

`IconDash.png`, `IconSwordWave.png`, `IconSpinSlash.png`, and `IconAshenJudgment.png` were generated specifically for this project. The HUD labels the keys Shift, Q, E and R separately, so the PNGs contain no text.

`GravewindRanger/` contains four character-specific ImageGen assets for Mist Step, Wraith Fan, Grave Snare, and Nightfall. Each icon is a separate transparent PNG with no embedded key or label text.
