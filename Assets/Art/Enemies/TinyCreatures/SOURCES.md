# Enemy sprite sources

- `PoisonSlime.png`, `Bat.png`, `DarkMage.png`, `EliteKnight.png`: selected original 16x16 tiles from **Tiny Creatures** by Clint Bellanger, CC0 1.0. The full license is in `License.txt`; attribution is appreciated but not required. Source: https://opengameart.org/node/160872
- `SkeletonArcher.png`, `BoneSentinel.png`, `SkeletonKing.png`: original sprites generated for this project, guided by the Tiny Creatures pixel-art style reference. They are not part of the CC0 pack.
- Skeleton Warrior keeps the project's existing animated `Skeleton.prefab` art so its animation clips continue to work.

The tiny tiles are imported with point filtering and no compression. Generated sprites use point filtering and a lower import size so they remain crisp and fit the existing prefab scale.
